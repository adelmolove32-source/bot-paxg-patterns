# Bot Trading BTC/ETH

Bot de trading com sinais no Telegram.

## Configuracao
- Capital: $200 por ativo
- BTC: 3m | ETH: 5m
- Filtro: 0.5% minimo
- R:R 1:3

## Como rodar
```bash
pip install -r requirements.txt
python telegram_bot.py
```

## Comandos Telegram
- /start - Inicio
- /signals - Sinais atuais
- /status - Status do bot
- /saldo - Saldo simulado
- /backtest - Resultado 60d
